## ⚽ What it's about

Until now, to see the game's **full names, ratings and squads** you had to copy a Sider module by hand and edit `sider.ini`. From this version on, **the editor does it for you**: click *Connect Sider folder* and you're done. And if the database isn't there yet, it tells you exactly what to do in the game.

Also, with that copy of the database the editor now **shows the real squad of teams that are empty in your EDIT**, and you can move them into the EDIT with one click.

---

## 🔌 The Sider module installs itself

When you click **Connect Sider folder** and pick your game folder (the one with `sider.exe`), the editor:

| | What it does | Details |
|:-:|---|---|
| 📄 | Copies `edit21_db.lua` into `modules\` | If you already had an old version, it updates it and saves the previous one as `edit21_db.lua.anterior` |
| ⚙️ | Adds `lua.module = "edit21_db.lua"` to `sider.ini` | It puts it below your other modules and turns on `lua.enabled`. It saves a backup first: `sider.ini.bak-pes-editor` |
| 📁 | Creates `content\edit21-db` | And a fallback folder, `content\pes-editor-db`, in case Windows won't allow writing to the first one |

> [!NOTE]
> The module is **read-only**: it doesn't change anything in the game or your game files. When PES loads its database (`common\etc\pesdb\*.bin`), it saves a copy exactly as the game uses it, with everything your game adds. If you'd rather install it by hand, it's attached below under **Assets**.

## 🧭 If the database isn't loaded, the editor lets you know

The first time (or if some file is missing) this warning shows up with the steps:

<div align="center">
<img alt="Warning: The game database isn't loaded" src="https://raw.githubusercontent.com/Agustinioquino/pes-editor/main/docs/releases/v0.017/aviso-base.png" width="90%">
</div>

1. Open **PES 2021 with Sider** and wait for the **main menu**.
2. Go to **Match › Friendly** up to **team selection**. That's where the game finishes loading the database.
3. **Close the game.**
4. Go back to the editor and click **"Done: read again"**.

You only do this **once**. If you update your game, do it again so the copy stays up to date.

## 📋 Database squads for empty teams

With the copy of `Team.bin` and `PlayerAssignment.bin`, the editor knows which players each of the game's **750 teams** has. If you open a team that has no squad in your EDIT, you'll see the one that comes with the game at the top, with shirt number, position and rating:

<div align="center">
<img alt="Squad per the game database" src="https://raw.githubusercontent.com/Agustinioquino/pes-editor/main/docs/releases/v0.017/plantel-de-la-base.png" width="90%">
</div>

- Click a player to open their profile; if they're not in your EDIT yet, the editor offers to add them.
- **Copy this squad to my EDIT** adds them to the team with their skills. If you change your mind, **Ctrl+Z**.
- To see empty teams in the list, turn on **"Include without squad"**.

Players who are in the database but not in your EDIT are now read with **skills, height, age, nationality and positions**, so their rating and value are calculated the same way as edited ones.

## 🛠️ Module v1.3: clearer when something goes wrong

- It copies **all** the database files (Player, Team, PlayerAssignment, Coach, Stadium, Competition, Tactics and the rest), not a fixed list.
- It leaves an `index.txt` with what it copied and an `estado.txt` with the latest result.
- If Windows won't let it write, it **logs the exact error in `sider.log`** and tries `content\pes-editor-db`. The editor reads that log and shows it to you in the warning.

> [!TIP]
> **Getting "Permission denied" or the warning won't go away?** That's Windows blocking the game. Go to **Windows Security › Virus & threat protection › Ransomware protection › Controlled folder access** and click **Allow an app through Controlled folder access** → `PES2021.exe`. Then repeat steps 1 to 4.
