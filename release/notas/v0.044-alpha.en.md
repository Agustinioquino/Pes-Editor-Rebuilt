## ⚽ The one we've all been waiting for

This is the version we were most eager to release. 🥹

Until today, if your Sider folder was inside **`C:\Program Files (x86)`** (right where Steam installs PES 2021, and where lots of mod setups keep it), Chrome stopped you dead with a *"Can't open this folder… it contains system files"*. You could look, but you couldn't save a single crest. And it wasn't the editor's fault: **no web page can write there**. We tried everything, we even dug through Chrome's source code, and there's no shortcut.

So we did the only thing left: **we took the editor out of the browser**. 🚀

Now you download an **.exe**, open it with a double click and you've got **PES Editor Rebuilt in its own window**, with its new logo on the desktop and in the Start menu, **connected to your Sider folder right where it is**. No moving it, no tricks, and with permission to save to the game. It's the beginning of something big: with the editor living on your PC, the mod-making shortcuts coming next will be able to do a lot more.

---

## ⬇️ Install it in 1 minute

1. Download **[PES-Editor-Rebuilt-Setup.exe](https://github.com/Agustinioquino/Pes-Editor-Rebuilt/releases/download/v0.044-alpha/PES-Editor-Rebuilt-Setup.exe)** (or the **[portable version](https://github.com/Agustinioquino/Pes-Editor-Rebuilt/releases/download/v0.044-alpha/PES-Editor-Rebuilt-Portable.exe)**, which opens without installing anything).
2. If Windows shows **"Windows protected your PC"**, click **More info › Run anyway**. It shows up because the app doesn't have a digital signature yet: it's the same one that's built, in plain view of everyone, in this repository.
3. Open **PES Editor Rebuilt**, pick your **Documents** folder and then **Connect Sider folder**.
4. Done. Next time it goes straight in. 🎉

## 🔧 sider.ini fixes itself

If you move the Sider folder and your `sider.ini` had full paths to the old folder (`cpk.root = "C:\Program Files…\livecpk\…"`), when you connect it **the editor changes them to relative paths** (`.\livecpk\…`) so Sider keeps finding them. It saves a copy in `sider.ini.bak-pes-editor` first, just in case.
