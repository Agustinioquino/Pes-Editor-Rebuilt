# 🧩 The Sider tab understands your game

**[▶ Open PES Editor Rebuilt](https://agustinioquino.github.io/Pes-Editor-Rebuilt/)** · **[⬇️ Windows app (.exe)](https://github.com/Agustinioquino/Pes-Editor-Rebuilt/releases/download/v0.046-alpha/PES-Editor-Rebuilt-Setup.exe)** · [📦 Portable version](https://github.com/Agustinioquino/Pes-Editor-Rebuilt/releases/download/v0.046-alpha/PES-Editor-Rebuilt-Portable.exe)

</div>

The Sider tab arrived in v0.045 showing what your game loads. With a game full of mods, with dozens of folders and modules, the questions came up: **what does this folder do?**, **why does it say this module is missing if it's right there?**, **why does nothing happen when I click add?** 🤔

This version answers all of that.

## 📖 What each thing does, in one line

Every content folder, every module and every content directory now has **a line that says what it changes in the game**. There are more than **40 categories** and more than **60 known modules**:

- 🕺 **Animations and poses**: the Edit mode poses and the pre-match (the `anime` folder).
- 🚩 **Fan banners**: flags in the stands per team and competition (the `common_ad` folder).
- 🎬 **Scenes and cutscenes**: fouls, goals, walk-outs, man of the match (FoulScenes, CutScenes…).
- 👥 **Crowd**: how many home and away fans there are, choreographies, ball boys.
- 🎽 **Sleeve logos**, 📋 **Master League**, 🎮 **gameplay**, 🎥 **cameras** and much more.

**Cameras are described by their name**: `penaltyCam` is the penalty camera and `ReplayCamera` the replay one. And if a module isn't on the list, the editor **reads the file itself** and uses what it says at the top.

<img alt="The content folders in Classic mode, each with the module that uses it and what it does: foul-scenes with FoulScenes.lua, master league selector with masterleague.lua, referee_kit-server with RefKitServer.lua" src="https://raw.githubusercontent.com/Agustinioquino/Pes-Editor-Rebuilt/main/docs/releases/v0.046/sider-content.png" width="100%">

## 🔍 It looks inside each folder

Besides the PES 2021 paths, the editor looks for **folder names that give away the content**, up to 7 levels deep: `anime`, `common_ad`, `demo`, `scoreboard`, `turf`… That way a mod called "edit mod" gets classified correctly even if its name says nothing.

**It works the same with base PES 2021, with mods or with Football Life.** Nothing is tied to any particular install.

## ⚡ Adding, removing and moving show up instantly

You'd click "＋" on a livecpk folder or a module and… nothing. The change was there, but **the list didn't update** until the file was read again. Now the new item appears at the end of its list, **highlighted**, with a notice, and the button disappears. Same when removing, moving, undoing or applying the text.

<img alt="In PES 6 Edit, the just-added Botines-2026 folder appears highlighted at the end of the list and its button is no longer among the folders missing from sider.ini" src="https://raw.githubusercontent.com/Agustinioquino/Pes-Editor-Rebuilt/main/docs/releases/v0.046/sider-agregada.png" width="100%">

## 🩹 The "missing" modules that were there all along

- Modules in **subfolders** of modules (like `modules\GRAND\Crowd-Server.lua`) no longer show up as missing.
- If a `lua.module` is **misspelled** (a missing letter, a hyphen instead of an underscore…), the row asks **"Is it FreeHeartEngine.lua? Fix"** and the button fixes the line.
- Content folders are **linked to the module that names them in its code**, and if none uses them, it says so.
- One quote too many or too few in a path no longer makes a folder look like it doesn't exist.
- **Repeated folders** say which path is repeated and on which rows. Sider uses the first one.
