## ⚽ What it's about

In PES 2021 the EDIT only stores players that were edited at some point. That's why the **Players** tab showed very few (on the test PC, 10), even though the game has thousands.

From this version on, with the game database copied by the Sider module, **Players shows everyone**: in the test, **27,192 players**, each with their team, shirt number and all their skills.

---

## 👥 Two lists: your EDIT and the game

Above the list there are two buttons:

| Button | What it shows |
|---|---|
| **My EDIT** | The players stored in your EDIT. You edit them as always |
| **From the game** | The whole game database, sorted by rating |

- If your EDIT has no players, the tab starts straight in **From the game**.
- The tab shows the database total (for example *Players 27.2k*). If you hover over it, it tells you how many there are in each list.
- To find someone, search by **name, ID or team**. You can also filter by position or by **"Only those not in my EDIT"**.
- With no search you see the 250 highest rated; when you search, everyone who matches shows up.

## 📋 The profile of each player from the game

It's **read-only** and shows the same things the game uses:

- face, position, nationality, age, height and rating;
- their teams with the shirt number (click one to go to that squad);
- all skills as bars, plus weak foot, form and injury resistance.

### Want to change it?

Click **"Add to my EDIT to edit it"**. The player is copied to your EDIT with all their skills and their editable profile opens, like any other. The face and name still come from the game. If you change your mind, **Ctrl+Z**.

## 🔎 The search box at the top finds them too

With the **/** key or the search box at the top, players from the game who aren't in any squad of your EDIT now show up too, marked as **"Game database"**. Picking one opens their profile.

## ✏️ Other changes

- The editor, the README and the Sider module now talk about **"the game"** instead of naming a specific mod set: PES Editor works with any game setup that uses Sider.

---

## 🧭 If you haven't copied the game database yet

1. Open PES Editor and click **Connect Sider folder**: the `edit21_db.lua` module installs itself.
2. Open **PES 2021 with Sider** and get to the **main menu**.
3. Go to **Match › Friendly** up to **team selection** and close the game.
4. Go back to the editor and click **"Done: read again"**.
