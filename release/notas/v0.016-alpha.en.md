## ⚽ PES Editor v0.016 alpha · Tidy locker room

An internal cleanup version: **no feature changes**, but the code is now much easier to read and maintain.

### 🧩 Code
- `index.html` went from **3.6 MB to 5 KB**: the styles are in `css/editor.css` and the code is in the `js/` folder, one file for each part of the editor (squad, formation, kits, 3D, player, graphics…). The README explains what each one does.
- We checked for duplicate or unused functions, and removed the one that opened folders with the old buttons.
- The tab icon is now a file (`icons/favicon-64.png`).

### ⚡ Loading
- Since it's split up, the browser caches each file and on later visits only downloads what changed.
- The installable app stores all the files so it works without internet.

> **Alpha** version: keep a copy of your EDIT before you start. Something broken? Tell us in [Issues](https://github.com/Agustinioquino/pes-editor/issues/new/choose).
