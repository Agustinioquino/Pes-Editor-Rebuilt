# 📨 Fonts for someone else's Sider

**[▶ Open PES Editor Rebuilt](https://agustinioquino.github.io/Pes-Editor-Rebuilt/)** · **[⬇️ Windows app (.exe)](https://github.com/Agustinioquino/Pes-Editor-Rebuilt/releases/download/v0.063-alpha/PES-Editor-Rebuilt-Setup.exe)** · [📦 Portable version](https://github.com/Agustinioquino/Pes-Editor-Rebuilt/releases/download/v0.063-alpha/PES-Editor-Rebuilt-Portable.exe)

</div>

Making a shirt font for a friend? Their patch may keep the team in another folder and use another letter texture. Now the **.zip** comes out with **their** names, so it works the first time. ⚽

## 📨 For someone else's Sider

In **Kit Studio Pro → 🔤 Fonts**, step 4, the new **📨 For someone else's Sider** section reads one of their files:

- **sider.log** (the best one): it has the team folder and the letter texture of each kit, exactly as their game loads them.
- **map.txt**: the team folder.
- **config.txt** of a kit: the texture that kit uses (NameFontFile).

The .zip then comes out with:

- **Their team folder**, for example `content\kit-server\Bundesliga (Germany)\Schalke` instead of yours.
- **The letter texture each kit already uses**, for example `Font White`, so they don't have to touch their config.txt.
- **Your own config.txt is no longer included** in a .zip for someone else.
- The **README** says which Sider it was built for.

How to use it:

1. Ask for their **sider.log** after they open the game and go to the team's kits.
2. In **🔤 Fonts**, step 4, open **📨 For someone else's Sider** and load the file (or drag it onto the screen).
3. Press **⬇ Download .zip** and send it to them.

## ⬇️ Do I need to download anything?

**No.** It's all in the editor, and the Windows app loads it on its own the next time you open it (or when "A new version of the editor is available" shows up).

# 📨 Fuentes para el Sider de otra persona

**[▶ Abrir PES Editor Rebuilt](https://agustinioquino.github.io/Pes-Editor-Rebuilt/)** · **[⬇️ App para Windows (.exe)](https://github.com/Agustinioquino/Pes-Editor-Rebuilt/releases/download/v0.063-alpha/PES-Editor-Rebuilt-Setup.exe)** · [📦 Versión portátil](https://github.com/Agustinioquino/Pes-Editor-Rebuilt/releases/download/v0.063-alpha/PES-Editor-Rebuilt-Portable.exe)

</div>

¿Armás una fuente de camiseta para otra persona? Su patch puede guardar el equipo en otra carpeta y usar otra textura de letras. Ahora el **.zip** sale con **sus** nombres, así anda a la primera. ⚽

## 📨 Para el Sider de otra persona

En **Kit Studio Pro → 🔤 Fuentes**, paso 4, la sección nueva **📨 Para el Sider de otra persona** lee uno de sus archivos:

- **sider.log** (el mejor): trae la carpeta del equipo y la textura de letras de cada kit, tal como las carga su juego.
- **map.txt**: la carpeta del equipo.
- **config.txt** de un kit: la textura que usa ese kit (NameFontFile).

Con eso el .zip sale con:

- **Su carpeta del equipo**, por ejemplo `content\kit-server\Bundesliga (Germany)\Schalke` en vez de la tuya.
- **La textura de letras que ya usa cada kit**, por ejemplo `Font White`, así no tiene que tocar su config.txt.
- **Tu config.txt ya no va** en un .zip para otra persona.
- El **LEEME** dice para qué Sider se armó.

Cómo se usa:

1. Pedile su **sider.log** después de que abra el juego y entre a los uniformes del equipo.
2. En **🔤 Fuentes**, paso 4, abrí **📨 Para el Sider de otra persona** y cargá el archivo (o arrastralo a la pantalla).
3. Tocá **⬇ Descargar .zip** y mandáselo.

## ⬇️ ¿Tengo que descargar algo?

**No.** Todo está en el editor, y la app de Windows lo carga sola la próxima vez que la abras (o cuando aparezca "Hay una versión nueva del editor").
